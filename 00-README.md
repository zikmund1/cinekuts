# Cinekuts — Project Knowledge Base

This is a working knowledge base for **Cinekuts**, Vojtech's curated film & TV review brand (website + YouTube channel @cinekutss, with TikTok and Instagram as secondary channels). It consolidates everything decided, built, and planned across the project so far, organized by domain.

**Last compiled:** September 5, 2026 — reflects the state of the project as of this date. Treat these as living documents and update them as decisions change, not as a historical record.

## How to use this

Each file below stands alone — you can hand any one of them to a collaborator, another AI tool, or your future self without needing the others for context. Start with `01-brand-and-positioning.md` for the big picture, or jump straight to the domain you're working in.
